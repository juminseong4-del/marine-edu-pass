MARINE EDU-PASS — GitHub Pages 업로드용

1. GitHub에서 새 Repository를 만듭니다.
2. 이 폴더 안의 index.html, manifest.webmanifest, sw.js를 Repository 최상단에 올립니다.
3. Repository Settings → Pages → Deploy from a branch를 선택합니다.
4. Branch는 main / root로 선택하고 저장합니다.
5. 생성된 https://사용자이름.github.io/저장소이름/ 주소를 휴대폰에서 엽니다.
6. iPhone: Safari → 공유 → 홈 화면에 추가
7. Android: Chrome → ⋮ → 홈 화면에 추가

주의:
- 관리자 버전은 포함하지 않은 사용자 버전입니다.
- 개선 의견은 현재 브라우저의 로컬 저장 방식입니다. 여러 사람의 의견을 한 곳에 모으는 서버 기능은 관리자 버전에서 별도로 추가해야 합니다.
